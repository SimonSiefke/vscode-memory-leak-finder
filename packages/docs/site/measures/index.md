# Measure catalog

The repository exports a broad set of collectors. This index is generated from `packages/memory-leak-finder/src/parts/Measures/Measures.ts`, the implementation's public registry, so newly exported measures appear in the catalog automatically. Names below are readable CLI-style identifiers; check `--help` and the linked implementation for aliases and collector-specific options.

These entries identify what a collector measures, not a promise that every metric is available on every platform or process. Open its implementation and any linked guide before interpreting values. Detailed notes currently exist for selected measures; the remaining entries link to their collector source.
